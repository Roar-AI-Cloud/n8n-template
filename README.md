# n8n on Roar AI

The template behind **Launch n8n** in the Roar AI console. It is one line: the official
n8n image, at a tested version.

Everything that keeps your workflows safe is set by the platform when the app is created:
a database for workflows and credentials, an encryption key kept in your app's own
variables (paste in your old one to bring saved credentials across), and webhook URLs that
follow your app's address.

You do not need to fork this repository to use n8n on Roar AI.
